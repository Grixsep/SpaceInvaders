# SpaceInvaders
[![Demo](https://img.shields.io/badge/Demo-Live-green?style=for-the-badge&logo=github)](https://grixsep.github.io/SpaceInvaders/)

> ⚠️ **Archived Project**  
> This project is no longer being maintained. It was created for learning purposes.

A small, unfinished web-based game inspired by **Space Invaders**, built to explore JavaScript programming and simple game development.

🔗 [Play the demo](https://grixsep.github.io/SpaceInvaders/)

## Features
- Basic player movement and shooting
- Simple enemy behavior
- HTML5 Canvas rendering
- Written in vanilla JavaScript

## Status
This project is **incomplete** and has been archived. It was created as part of a personal learning journey and will not receive future updates.
